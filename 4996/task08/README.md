# Задача 08 - Cгенерировать случайный пароль заданной длины с наборами символов

## Участники группы
Захаров П.И.

## Описание решения
Реализован генератор случайного пароля с помощью класса Random и списков, включение\отключение функций реализовано через меню.

## Как запустить
Скачать .NET SDK 
Открыть командную строку
Зайти в папку \git-practice-1\4996\task08\random_password
прописать dotnet run Program.cs
