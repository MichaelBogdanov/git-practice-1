## Описание решения

Реализован алгоритм **быстрой сортировки (QuickSort)** без использования встроенных методов сортировки.

### Алгоритм работы:
1. **Чтение данных** — числа считываются из файла (разделители: пробелы, табуляция, новая строка)
2. **Выбор опорного элемента** — в данной реализации выбирается последний элемент массива
3. **Разделение (Partition)** — массив разделяется на две части: элементы меньше опорного и больше опорного
4. **Рекурсивная сортировка** — процесс повторяется для каждой части до тех пор, пока массив не будет отсортирован

### Почему QuickSort:
- Эффективен для больших массивов
- Требует O(log N) дополнительной памяти (для стека рекурсии)
- Средняя сложность O(N log N)
