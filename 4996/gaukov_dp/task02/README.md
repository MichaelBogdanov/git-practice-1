## Описание решения

Программа предназначена для анализа текстового файла и подсчёта базовых статистик текста.

### Алгоритм работы:
1. **Чтение файла** — текст считывается построчно из файла, путь к которому передаётся в качестве аргумента командной строки
2. **Токенизация** — каждая строка разбивается на слова по разделителям (пробельные символы и знаки препинания)
3. **Подсчёт** — считается количество строк и слов в тексте
4. **Поиск самого длинного слова** — в процессе обработки отслеживается слово с максимальной длиной

### Разделители слов:
- Пробельные символы: пробел, табуляция, перенос строки
- Знаки препинания: `, . ! ? ; : - ( ) [ ] { } " ' < > / \ | @ # $ % ^ & * _ + =`
