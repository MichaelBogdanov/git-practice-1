## Описание решения

Программа генерирует случайный пароль заданной длины с настраиваемыми наборами символов.

### Алгоритм работы:
1. **Чтение параметров** — из файла считываются длина пароля и опции (цифры, прописные, строчные, спецсимволы)
2. **Формирование наборов** — создаются пулы символов для каждого включённого типа
3. **Гарантия наличия** — минимум один символ из каждого включённого набора обязательно добавляется в пароль
4. **Заполнение длины** — оставшиеся позиции заполняются случайными символами из всех доступных наборов
5. **Перемешивание** — используется алгоритм Fisher-Yates для случайного порядка символов

### Наборы символов:
- **Строчные буквы:** a-z (26 символов)
- **Прописные буквы:** A-Z (26 символов)
- **Цифры:** 0-9 (10 символов)
- **Спецсимволы:** !@#$%^&*()_+-=[]{}|;:,.<>? (25 символов)
