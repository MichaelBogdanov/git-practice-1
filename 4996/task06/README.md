# Задача 06 - Реализация сортировки (без встроенных) в данном случае BubbleSort

## Участники группы
Захаров П.И.

## Описание решения
Сортировка массива array реализована с помощью сортировки BubbleSort, которая проходится по массиву и сравнивает ближайшие элементы. Сложность алгоритма O(n^2)

## Как запустить
Скачать .NET SDK 
Открыть командную строку
Зайти в папку \git-practice-1\4996\task06\git-practice-task-06
прописать dotnet run Program.cs
