# Задача 09 — Сжатие строки (RLE)

## Участники группы
Емельянов И.А.

## Описание решения
Реализован алгоритм Run-Length Encoding (RLE) для сжатия последовательностей повторяющихся символов.
Алгоритм проходит по строке за один цикл, сравнивая текущий символ с последующим. Если символы идентичны, инкрементируется счетчик. При смене символа в результирующую строку записывается пара символ + количество.
Процесс восстановления использует чтение символа и поиск всех последующих цифр для определения коэффициента повторения. Реализована поддержка многозначных чисел.
Поддерживаются любые символы.

## Как запустить
python solution.py input.txt
