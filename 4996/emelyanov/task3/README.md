# Задача 03 — Переворот слов в тексте

## Участники группы
Емельянов И.А.

## Описание решения
Текст разбивается на слова с помощью метода .split(), который игнорирует произвольное количество пробельных символов. Порядок элементов в списке инвертируется методом срезов
Финальная строка формируется методом .join(), восстанавливающим единичные пробелы между блоками слов.

## Как запустить
python solution.py input.txt
