# Задача 02 — Подсчёт слов в тексте

## Участники группы
Емельянов И.А.

## Описание решения
Программа считывает текстовый файл и выполняет базовый анализ содержимого.
Для корректного подсчета слов используется очистка от пунктуации с помощью таблицы подстановок string.punctuation.
Самое длинное слово определяется через встроенную функцию max() с ключом len.

## Как запустить
python solution.py input.txt
