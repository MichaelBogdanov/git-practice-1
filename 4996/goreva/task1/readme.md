# Задача 01 — Проверка корректности скобок

## Участники группы
Горева А.М

## Описание решения
Создан словарь с вариантами скобок
Все открывающие скобки из введенной строки записываются в список пока не встретится закрывающая
Если она не подходит к последней открывающей или список скобок пуст, то функция возвращает False
В конце проверяется длина списка, если она = 0, то все скобки закрыты => возврат True

## Как запустить
python solution.py
