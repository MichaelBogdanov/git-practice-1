# Задача 10 — Проверка IP-адреса

## Участники группы
Горева А.М

## Описание решения
Введенная строка проверяется на наличие : и .
Если найдена '.', то строка делится и проверяется на соответствие IPv4,
если найдено ':', то строка делится и проверяется на соответствие IPv6,
если не найден ни один из этих символов, то функция возвращае invalid

## Как запустить
python solution.py
