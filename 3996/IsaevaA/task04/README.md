# Задача 4 — Удаление дубликатов, сохраняя порядок

## Участник
Каретников

## Описание
Программа убирает повторяющиеся числа из введённого списка.
Порядок первых вхождений сохраняется.

## Как работает
Создаю новый список. Для каждого числа из ввода проверяю, есть ли оно уже в новом списке.
Если нет — добавляю.

## Запуск
Ввести числа через пробел, нажать Enter.

## Пример
Ввод: 1 2 3 2 4 1 5
Вывод: 1 2 3 4 5
