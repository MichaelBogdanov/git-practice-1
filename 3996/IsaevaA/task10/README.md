# Задача 10 — Проверка IP-адреса

## Участник
Каретников

## Описание
Проверяет, является ли строка правильным IP-адресом.

## Условия
- 4 числа через точку
- числа от 0 до 255
- без ведущих нулей

## Запуск
Ввести IP, нажать Enter.

## Пример
Ввод: 192.168.0.1  
Вывод: Верный IP

Ввод: 192.168.01.1  
Вывод: Неверный IP
