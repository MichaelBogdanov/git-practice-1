# Задача 11 — Проверка шахматного хода

## Участник
Каретников

## Описание
Проверяет, можно ли попасть из одной клетки в другую ходом ферзя.
То есть по горизонтали, вертикали или диагонали.

## Как работает
Перевожу буквы в числа. Сравниваю координаты.

## Запуск
Ввести две клетки (например, a1 и h8).

## Пример
Ввод: a1 → h8  
Вывод: Ход возможен

Ввод: a1 → b3  
Вывод: Ход невозможен
