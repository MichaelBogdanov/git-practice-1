# Задача 06 --- Реализация сортировки (без встроенных)

## Участник группы

Сергеева И. А.

## Описание решения
Реализована сортировка пузырьком (Bubble Sort) без использования встроенных функций.

Алгоритм:
1. Копируем исходный массив
2. Проходим по массиву `n-1` раз
3. Сравниваем соседние элементы
4. Меняем местами, если левый больше правого
5. Возвращаем отсортированный массив

Сложность:
- `O(n²)` — в среднем и худшем случае (если массив не отсортирован, требуется много перестановок)
- `O(n)` — в лучшем случае (если массив уже отсортирован, достаточно одного прохода)

Память:
- `O(1)` — используется только исходный массив и несколько вспомогательных переменных

## Как запустить

``` bash
python solution.py input.txt
```
