# Задача 05 --- Римские числа (двунаправленный конвертер)

## Участник группы

Сергеева И. А.

## Описание решения
Программа конвертирует числа между римской и арабской системами счисления.

**Арабское → Римское:**
- Используются параллельные списки `numbers` и `letters`
- Жадный алгоритм: пока число больше значения — добавляем символ

**Римское → Арабское:**
- Проход по строке справа налево
- Если текущее значение меньше предыдущего — вычитаем, иначе складываем

## Как запустить

```bash
python solution.py input.txt
```
