# Задача 03 --- Переворот слов в тексте

## Участник группы

Сергеева И. А.

## Описание решения

Программа читает текст из файла, переворачивает порядок слов и сохраняет
результат.

Алгоритм работы: 
1. Чтение текста из файла `input.txt` 
2. Удаление пробелов в начале и конце строки (`strip`) 
3. Разбиение строки на слова (`split`) 
4. Проход по словам в обратном порядке и добавление в новый список 
5. Объединение слов с пробелом и запись в `output.txt`

## Как запустить

``` bash
python solution.py input.txt
```
