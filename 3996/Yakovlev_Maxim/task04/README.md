# Удаление дубликатов, сохраняя порядок

## Участники группы
Яковлев М.М.

## Описание решения
Программа читает текст из файла, удаляя дубликаты, сохраняя порпядок.
**Основные возможности:**
Опции: удалить повторяющиеся элементы, сохранив исходный порядок

## Как запустить
1. Открыть slnx файл

2. Поместить входной файл `file.txt` в папку с программой

3. Запустить программу

4. Скомпилировать программу

5. Результат будет сохранен в файл `output.txt`

## Пример работы

**Содержимое file.txt:**
```
  Андей Никита Андрей Никита 123 321 123
```

**Содержимое output.txt после запуска:**
```
Андей Никита 123 321
```
