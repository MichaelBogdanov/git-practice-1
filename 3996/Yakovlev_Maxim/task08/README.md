# Генератор случайных паролей

## Участники группы
Богданов М.М.
Яковлев М.М.

## Описание решения
Программа генерирует случайный пароль заданной длины с возможностью выбора наборов символов.
**Основные возможности:**
Опции: включать/исключать цифры, прописные/строчные буквы, спецсимволы

## Как запустить
1. Открыть slnx файл


2. Скомпилировать программу


3. Следовать инструкциям в консоли:
- Ввести длину пароля
- Ответить на вопросы о включении наборов символов (y/n)

## Пример работы
```
Введите длину пароля: 12
Включать цифры? (y/n): y
Включать прописные буквы? (y/n): y
Включать строчные буквы? (y/n): y
Включать спецсимволы? (y/n): y

Сгенерированный пароль: K7x@p9L#mQ2$
```
