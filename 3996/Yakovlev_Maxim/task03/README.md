# Переворот порядка слов в тексте

## Участники группы
Богданов М.М.
Яковлев М.М.

## Описание решения
Программа читает текст из файла, переворачивает порядок слов и сохраняет результат в новый файл.
**Основные возможности:**
Опции: Переворот слов в предложении

## Как запустить
1. Открыть slnx файл

2. Поместить входной файл `input.txt` в папку с программой

3. Запустить программу

4. Скомпилировать программу

5. Результат будет сохранен в файл `output.txt`

## Пример работы

**Содержимое input.txt:**
```
  Привет   мир!   Это   тестовый   текст  
```

**Содержимое output.txt после запуска:**
```
текст тестовый Это мир! Привет
```
