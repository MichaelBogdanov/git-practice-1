# Задача 8 — Генератор пароля

## Участник
Каретников

## Описание
Программа генерирует случайный пароль заданной длины.
Использует буквы (маленькие и большие), цифры и символы.

## Как работает
Берет случайные символы из строки со всеми разрешенными символами.
Длину вводит пользователь.

## Запуск
Запустить, ввести нужную длину, получить пароль.

## Пример
Ввод: 10
Вывод: aB3$kL9pQ2
