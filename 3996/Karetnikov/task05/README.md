# Задача 5 — Римские числа

## Участник
Каретников

## Описание
Программа переводит арабские числа в римские и обратно.
Если вводим цифры — получаем римское число.
Если вводим римское число — получаем арабское.

## Как работает
Для перевода арабских в римские использую таблицы с тысячами, сотнями, десятками и единицами.
Для перевода римских в арабские складываю значения букв, потом вычитаю лишнее для IV, IX и т.д.

## Запуск
Просто запустить exe файл и ввести число.

## Пример
Ввод: 2024
Вывод: MMXXIV

Ввод: MMXXIV
Вывод: 2024
