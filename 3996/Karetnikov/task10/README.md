# Задача 10 — Проверка IP-адреса

## Участник
Каретников

## Описание
Программа проверяет, является ли строка правильным IP-адресом.

## Правила
- Должно быть 4 числа через точки
- Каждое число от 0 до 255
- Не может быть ведущих нулей (типа 01)
- Только цифры и точки

## Запуск
Запустить, ввести IP, получить результат.

## Пример
Ввод: 192.168.1.1
Вывод: Верный IP

Ввод: 256.1.2.3
Вывод: Неверный IP
