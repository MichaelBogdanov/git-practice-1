# Задача 06 — Реализация сортировки

## Участники группы
Синицына Е.Л.

## Описание решения
Реализованы три алгоритма сортировки:
- **Сортировка слиянием (Merge Sort)**
- **Быстрая сортировка (Quick Sort)**
- **Пузырьковая сортировка (Bubble Sort)**

## Сложность алгоритмов

### 1. Сортировка слиянием (Merge Sort)
- **Временная сложность**: O(n log n) в лучшем, среднем и худшем случае
- **Пространственная сложность**: O(n)
- **Стабильность**: стабильная
- **Принцип работы**: разделение массива на две половины, рекурсивная сортировка каждой половины, слияние отсортированных половин

### 2. Быстрая сортировка (Quick Sort)
- **Временная сложность**: 
  - Лучший и средний: O(n log n)
  - Худший: O(n²) (при выборе неудачного опорного элемента)
- **Пространственная сложность**: O(log n) для рекурсивных вызовов
- **Стабильность**: нестабильная
- **Принцип работы**: выбор опорного элемента, разделение массива на элементы меньше и больше опорного, рекурсивная сортировка подмассивов

### 3. Пузырьковая сортировка (Bubble Sort)
- **Временная сложность**: 
  - Лучший: O(n) (уже отсортированный массив)
  - Средний и худший: O(n²)
- **Пространственная сложность**: O(1)
- **Стабильность**: стабильная
- **Принцип работы**: многократный проход по массиву, сравнение соседних элементов и их обмен при необходимости
