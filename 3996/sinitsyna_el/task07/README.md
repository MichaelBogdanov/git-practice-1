# Задача 07 — Подсчёт частоты символов

## Участники группы
Синицына Е.Л.

## Описание решения
Программа анализирует текстовый файл и выводит частоту каждого символа.

## Особенности
- Опция `-i` для игнорирования регистра
- Сортировка результатов по убыванию частоты
- Вывод абсолютной частоты и процентного соотношения

## Как запустить

```bash
# С учетом регистра
dotnet run test.txt

# Без учета регистра
dotnet run test.txt -i
