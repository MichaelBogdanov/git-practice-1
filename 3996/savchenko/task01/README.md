# Задача 01 — Проверка корректности скобок

## Участник группы

## Описание решения
Для проверки корректности вложенности скобок использована структура данных **Stack (Стек)**. 
Алгоритм работает следующим образом:
1. Проходим по строке посимвольно.
2. Если встречаем открывающую скобку (`(`, `[`, `{`), добавляем её в стек.
3. Если встречаем закрывающую скобку, проверяем:
   - Не пуст ли стек (если пуст — скобка лишняя).
   - Соответствует ли верхний элемент стека типу закрывающей скобки.
4. После завершения прохода проверяем, пуст ли стек (если не пуст — какая-то скобка не закрыта).

Игнорируются все символы, кроме трех видов скобок.

## Как запустить
Используйте компилятор C# (csc или Visual Studio):
"csc solution.cs"
