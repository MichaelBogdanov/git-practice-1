# Задача 07 — Подсчёт частоты символов

## Участник группы
Савченко Д.М. (Группа 3996)

## Описание решения
Программа анализирует текстовый файл и выводит статистику использования символов.
- **Алгоритм**: Используется словарь `Dictionary<char, int>`, где ключом является символ, а значением — количество его вхождений.
- **Опции**: Реализован перевод текста в нижний регистр для игнорирования разницы между заглавными и строчными буквами.
- **Сортировка**: Данные выводятся в порядке убывания частоты (от самых частых к самым редким).

## Как запустить
1. Скомпилируйте файл:
   "csc solution.cs"
2. Запустите программу, указав текстовый файл:
   "solution.exe input.txt"
