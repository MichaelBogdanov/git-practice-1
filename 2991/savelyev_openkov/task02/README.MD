##Описание решения
Программа анализирует текстовый файл и подсчитывает:

Количество строк в файле (по символу переноса строки)

Количество слов (разделение по пробелам после удаления пунктуации)

Самое длинное слово и его длину

Для удаления пунктуации используется str.maketrans() и string.punctuation.
Поиск самого длинного слова выполняется с помощью функции max() с ключом len.

##Как запустить
text
python 2.py
Файл для анализа должен называться input.txt и находиться в той же директории, что и скрипт.
