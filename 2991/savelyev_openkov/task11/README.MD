#Задача 11 - Проверка хода шахматной фигуры

##Участники группы
Савельев С.О.
Опёнков В.В.

##Описание решения
Программа проверяет корректность хода шахматной фигуры с позиции start на позицию end на доске 8×8, заданной в файле input.txt.

Формат доски: 8 строк по 8 символов:

Заглавные буквы - белые фигуры (K, Q, R, B, N, P)

Строчные буквы - чёрные фигуры (k, q, r, b, n, p)

Точка (.) - пустая клетка

Поддерживаемые фигуры: король, ферзь, ладья, слон, конь, пешка.

##Проверки:

Корректность входных позиций (формат "буква+цифра", например e2)

Наличие фигуры в начальной клетке

Невозможность пойти на свою фигуру

Свободный путь для ладьи, слона и ферзя (нет фигур между start и end)

Специфика хода для каждой фигуры (для пешки учитывается первый ход на 2 клетки и взятие)

#Как запустить
text
python 11.py e2 e4
Доска должна находиться в файле input.txt в той же директории, что и скрипт.
