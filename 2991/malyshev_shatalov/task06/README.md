# Задача 06 — Сортировка QuickSort

## Участники группы
Шаталов, Малышев

## Описание решения
Реализована рекурсивная быстрая сортировка QuickSort. Первый элемент выбран в качестве опорного, массив разделяется на элементы меньше и больше опорного, рекурсивно сортируются подмассивы.

## Как запустить
Кнопка "run"
