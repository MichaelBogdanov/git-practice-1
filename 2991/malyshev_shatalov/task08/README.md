# Задача 08 — Генератор паролей

## Участники группы
Шаталов, Малышев

## Описание решения
Генерирует случайный пароль заданной длины. Поддерживает опции: -d (цифры), -U (заглавные), -l (строчные), -s (спецсимволы). Гарантирует минимум один символ из каждого включённого набора.

## Как запустить
В терминале python job3.py <длина> [-d] [-U] [-l] [-s]
