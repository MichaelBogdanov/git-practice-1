## Описание решения
В работе реализован алгоритм сортировки слиянием (Merge Sort) без использования встроенных функций и методов сортировки Python.

Алгоритм работает по принципу "разделяй и властвуй":
1. Список делится на две части.
2. Каждая часть рекурсивно сортируется.
3. Отсортированные части объединяются в один итоговый отсортированный список.

Для объединения двух отсортированных частей используется отдельная функция `merge`.

## Сложность алгоритма
- Временная сложность: **O(n log n)**
- Дополнительная память: **O(n)**
