# Задача 05 — Римские числа (двунаправленный конвертер)

## Участники группы
Стаскевич

## Описание решения
Реализован двунаправленный конвертер:
- из арабского числа в римскую запись;
- из римской записи в арабское число.

Поддерживается диапазон от 1 до 3999.
Для проверки корректности римской строки используется валидация по правилам записи римских чисел.

## Как запустить
Преобразование арабского числа в римское:
В терминале python solution.py 19
Наоборот:
В терминале python solution.py XIX
