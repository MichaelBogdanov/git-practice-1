# Задача 09 — Сжатие строки (Run-Length Encoding)

## Участники группы
Стаскевич

## Описание решения
Реализовано RLE-сжатие и декодирование строки.

Формат кодирования:
символ:количество;

Пример:
AAABBB111 → A:3;B:3;1:3;

Такой формат позволяет корректно работать с любыми символами, включая цифры.

## Как запустить
Кодирование:
В терминале python solution.py encode AAABBB111
Декодирование:
В терминале python solution.py decode "A:3;B:3;1:3;"
