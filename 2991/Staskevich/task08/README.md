# Задача 08 — Генератор пароля

## Участники группы
Стаскевич

## Описание решения
Реализован генератор случайного пароля заданной длины.

Поддерживаются опции:
- цифры;
- строчные буквы;
- заглавные буквы;
- специальные символы.

Если набор включён и длина пароля позволяет, в итоговом пароле гарантируется минимум один символ из каждого выбранного набора.

Для генерации используется модуль `secrets`.

## Как запустить
Пример генерации пароля длиной 12 символов:
В терминале python solution.py 12 --digits --lower --upper --special
