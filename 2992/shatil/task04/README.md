# Задача 04 — Удаление дубликатов, сохраняя порядок

## Участники группы
Шатиль Т.А.

## Описание решения
Считывается файл, все токены разделяются по пробельным символам.
Затем проходим по ним один раз, добавляя элемент в результат только если
он ещё не встречался — используем множество `seen` для проверки за O(1).
Таким образом порядок первого появления сохраняется, а дубликаты отбрасываются.

**Сложность:** O(n) по времени и памяти.

## Как запустить
```
python solution.py input.txt
```

## Пример
`input.txt`:
```
apple banana apple orange banana grape
```
Вывод:
```
apple banana orange grape
```
