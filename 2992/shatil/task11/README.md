# Задача 11 — Проверка шахматного хода

## Участники группы
Шатиль Т.А.

## Описание решения
Программа считывает из файла состояние шахматной доски (8 строк × 8 символов)
и строку с ходом в алгебраической нотации (например, `e2 e4`).

Поддерживаемые фигуры:
| Символ | Фигура  |
|--------|---------|
| K/k    | Король  |
| Q/q    | Ферзь   |
| R/r    | Ладья   |
| B/b    | Слон    |
| N/n    | Конь    |
| P/p    | Пешка   |
| .      | Пусто   |

Заглавные — белые, строчные — чёрные.

Логика проверки:
- Для скользящих фигур (Ладья, Слон, Ферзь) генерируются все клетки
  вдоль лучей до первого препятствия (учитывается блокировка).
- Конь прыгает через фигуры.
- Пешка ходит вперёд (или на 2 с начальной позиции) и бьёт по диагонали.
- Нельзя бить свою фигуру.

Формат входного файла:
```
........
........
........
...R....
........
........
........
........
d5 d8
```

## Как запустить
```
python solution.py board.txt
```
Вывод: `VALID` или `INVALID`
