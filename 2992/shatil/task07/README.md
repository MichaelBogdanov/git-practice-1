# Задача 07 — Подсчёт частоты символов

## Участники группы
Шатиль Т.А.

## Описание решения
Считываем файл целиком, затем с помощью `collections.Counter` подсчитываем
частоту каждого символа. Флаг `--ignore-case` приводит текст к нижнему
регистру перед подсчётом. Результат сортируется по убыванию частоты;
при одинаковой частоте — по алфавиту символа.

Спецсимволы (пробел, перенос строки, табуляция) выводятся с читаемыми
именами: `SPACE`, `NEWLINE`, `TAB`.

## Как запустить
```
python solution.py input.txt
python solution.py input.txt --ignore-case
```

## Пример вывода
```
Частота символов (с учётом регистра):
Символ          Частота
----------------------
a                     5
SPACE                 4
b                     3
...
```
