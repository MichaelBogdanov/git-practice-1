# Задача 8 — Генератор пароля

## Участник
Крючков

## Описание решения

**Алгоритм:**
1. Определяем наборы символов:
   - Строчные буквы: `a-z`
   - Прописные буквы: `A-Z`
   - Цифры: `0-9`
   - Спецсимволы: `!@#$%^&*()_-=+[]{}|;:,.<>?`
2. Объединяем все наборы в одну строку
3. Генерируем пароль заданной длины:
   - 12 раз случайно выбираем символ из объединенного набора
   - Используем `random.choice()` для выбора
4. Возвращаем получившуюся строку

**Почему пароль надежный:**
- Каждый символ выбирается случайно и независимо
- Используется 72 возможных символа (26+26+10+10)
- Количество возможных паролей: 72^12 ≈ 10^22
