
# Задача 3 — Переворот слов в тексте

## Участник
Крючков

## Описание решения

**Алгоритм:**
1. Используем регулярное выражение `\b\w+\b` для поиска всех слов
   - `\b` — граница слова (начало или конец)
   - `\w+` — одна или более букв, цифр или подчеркиваний
2. Получаем список всех слов в порядке их появления в тексте
3. Разворачиваем список: `words[::-1]`
4. Объединяем слова обратно в строку с одним пробелом между ними

**Что происходит с текстом:**
- Все знаки препинания, пробелы и переносы строк удаляются
- Регистр букв сохраняется
- Между словами всегда ровно один пробел
