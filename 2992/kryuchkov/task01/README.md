# Задача 1 — Проверка корректности скобок

## Участник
Крючков

## Описание решения

**Алгоритм:**
1. Создаем словарь, где ключ — открывающая скобка, значение — закрывающая: `{ '(': ')', '[': ']', '{': '}' }`
2. Создаем пустой стек (список) для хранения открывающих скобок
3. Проходим по каждому символу строки:
   - Если символ — открывающая скобка — добавляем ее в стек
   - Если символ — закрывающая скобка:
     - Если стек пуст -> возвращаем "NO" (закрывающая скобка без открывающей)
     - Достаем из стека последнюю открывающую скобку и проверяем, соответствует ли ей закрывающая
     - Если не соответствует → возвращаем "NO"
4. После обработки всех символов:
   - Если стек пуст -> возвращаем "YES" (все скобки закрыты)
   - Если стек не пуст -> возвращаем "NO" (остались незакрытые скобки)
