# Задача 01 — Проверка скобок



## Описание решения

Программа анализирует переданную строку и определяет, правильно ли расставлены скобки `()`, `\[]`, `{}`. Другие символы игнорируются.



### Алгоритм

1. Проход по каждому символу строки

2. Если символ открывающая скобка она помещается в список.

3. Если символ закрывающая скобка то проверяется список:

- Проверка, есть ли в списке элемент. Если список пуст то возвращается "NO"

- Иначе сравнивается верхний элемент списка с соответствующей открывающей скобкой. Если не совпадает "NO"

- Если совпадает то удаляется верхний элемент из списка

4. После обхода всех символов проверяется список: если он пуст "YES", иначе "NO".

python solution.py "(строка для проверки)"
