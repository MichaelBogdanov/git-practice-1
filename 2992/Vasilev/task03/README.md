# Задача 03 — Переворот слов в тексте

# Участники группы
Васильев Д.Р.

## Описание решения
Программа читает текстовый файл, переставляет слова в обратном порядке и удаляет лишние пробелы .

### Алгоритм
1. Считывается всё содержимое файла
2. Разбивается строка на слова по пробелам с помощью `split()`
3. Переворачивается полученный список слов
4. Объединяются слова в строку ровно с одни пробелом
5. Выводится результат

## Запуск
```bash
python solution.py input.txt
