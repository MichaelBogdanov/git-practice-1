# Задача 09 — RLE-сжатие и декодирование

# Участники группы
Васильев Д.Р.

## Описание решения
Программа реализует алгоритм RLE сжатия последовательностей одинаковых символов. Поддерживаются любые символы, числа могут быть многозначными


### Запуск
```bash
# Сжатие
python solution.py encode "AAABBBCCDAA"

# Декодирование
python solution.py decode "A3B3C2D1A2"
