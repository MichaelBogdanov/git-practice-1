# Задача 10 — Проверка IP-адреса

## Участники группы
Юрганов

## Описание решения
Программа проверяет строку на соответствие формату IPv4 (4 числа от 0 до 255 через точку) или IPv6 (8 групп по 1-4 шестнадцатеричных символа через двоеточие). Для IPv6 реализована нормализация — удаление ведущих нулей.

## Как запустить
python solution.py 192.168.1.1
python solution.py 2001:0db8:0000:0000:0000:ff00:0042:8329
