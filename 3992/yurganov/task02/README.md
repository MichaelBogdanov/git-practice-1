# Задача 02 — Подсчет слов

## Участники группы
Юрганов

## Описание решения
Программа считывает файл построчно. Каждая строка разбивается на слова с помощью регулярного выражения, которое оставляет только буквы и цифры. Считается общее количество строк и слов, а также ищется самое длинное слово.

## Как запустить
python solution.py input.txt
