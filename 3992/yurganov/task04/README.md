# Задача 04 — Удаление дубликатов

## Участники группы
Юрганов

## Описание решения
Программа считывает файл, разбивает содержимое на элементы по пробельным символам. Используется множество для отслеживания уже встреченных элементов. Результат формируется в виде строки без повторов с сохранением исходного порядка.

## Как запустить
python solution.py input.txt
