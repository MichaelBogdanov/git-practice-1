 Задача №7: Подсчёт частоты символов

 Описание
Программа анализирует текстовый файл и выводит частоту каждого символа. Результаты сортируются по убыванию частоты. Есть возможность игнорировать регистр букв.

Возможности
 Подсчёт всех символов (включая пробелы, переносы строк)
 Игнорирование регистра (опционально)
 Сортировка по убыванию частоты
 Отображение в процентах
 Красивое отображение спецсимволов
Поддержка кириллицы и Unicode

Установка и запуск

 Требования
 Python 3.x
 Стандартная библиотека: `collections`
