 Задача №2: Подсчёт слов

Описание
Программа анализирует текстовый файл и выводит статистику: количество строк, количество слов и самое длинное слово с его длиной. Слова отделяются пробельными символами и знаками пунктуации.

 Возможности
 Подсчёт количества строк в файле
 Подсчёт количества слов (с учётом пунктуации)
 Нахождение самого длинного слова
 Автоматическое удаление знаков пунктуации
 Обработка ошибки отсутствия файла
 Поддержка кириллицы (UTF-8)

 Требования
 Python 3.x
 Стандартные библиотеки: `string`
