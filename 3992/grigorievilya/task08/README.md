 Задача №8: Генератор пароля

 Описание
Простой генератор случайных паролей с возможностью выбора типов символов. Программа гарантирует, что в пароле будет хотя бы один символ из каждого выбранного набора (если длина пароля позволяет).

 Возможности
  Выбор длины пароля
  Включение/исключение цифр (0-9)
  Включение/исключение заглавных букв (A-Z)
  Включение/исключение строчных букв (a-z)
 Включение/исключение спецсимволов (!@#$%...)
 Гарантия минимум одного символа из каждого выбранного набора
 Проверка корректности ввода

Установка и запуск

 Требования
 Python 3.x
 Стандартные библиотеки: `random`, `string`

 Запуск
```bash
python password_generator.py
