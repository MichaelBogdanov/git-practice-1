## Описание решения
Генератор принимает требуемую длину и флаги включения наборов символов. Если набор включен, в пароль принудительно добавляется как минимум один символ из него (чтобы соответствовать требованию "минимум один символ из включенных наборов"). Остальной объем добивается рандомно из общего пула. Итоговый список перемешивается через `random.shuffle()` для случайного распределения символов.
