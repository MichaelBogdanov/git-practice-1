# Задача 01 — Проверка корректности скобок

## Участники группы
Фомин И.Д.

## Описание решения
Для решения используется структура данных "стек" (в Python реализована через обычный список `list`). Программа проходит по каждому символу строки: если встречает открывающую скобку — кладет её в стек, если закрывающую — проверяет, соответствует ли она последней открытой (которую достает из стека). Не-скобочные символы игнорируются.

## Как запустить
```bash
python solution.py
