# Задача 02 — Подсчёт слов

## Участники группы
Фомин И.Д.

## Описание решения
Скрипт читает файл `input.txt` и подсчитывает количество строк. Для разделения слов используется регулярное выражение `[^\w]+`, которое считает разделителем любую последовательность знаков препинания или пробелов. В процессе перебора списка слов скрипт находит самое длинное слово и считает общее их количество.

## Как запустить
```bash
python solution.py
