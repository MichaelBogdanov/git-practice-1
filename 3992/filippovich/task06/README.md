# Задача 06 — Алгоритм сортировки (QuickSort)

## Участник
Филиппович (filippovich)

## Описание решения
Реализована быстрая сортировка без встроенных функций.  
Массив разбивается на три части относительно опорного элемента - середины, рекурсивно сортируются левая и правая части.

## Оценка сложности
- Средний случай: O(n log n)
- Худший случай: O(n²)
- Лучший случай: O(n log n)

## Запуск
python solution.py input.txt
