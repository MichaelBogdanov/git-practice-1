# Задача 11 — Проверка шахматного хода

## Участники группы
Железков Ф.В.

## Описание решения
Программа загружает состояние шахматной доски из текстового файла (8 строк по 8 символов: заглавные — белые, строчные — чёрные, . — пустая клетка).
Затем запрашивает ход в формате e2 e4 и проверяет:

    Может ли фигура так пойти по своим правилам (пешка, конь, ладья, слон, ферзь, король).

    Учитываются столкновения с другими фигурами (свои нельзя бить, чужие — можно).

Вывод: VALID или INVALID.

## Как запустить
python Task11.py input.txt
