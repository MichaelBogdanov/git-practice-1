# Задача 6 — Сортировка слиянием

## Участники группы
Железков Ф.В.

## Описание решения
Реализован алгоритм сортировки слиянием без использования встроенных функций сортировки.
Алгоритм рекурсивно делит массив пополам до длины 1, затем сливает отсортированные половины.
Слияние выполняется за линейное время с использованием дополнительного массива.

## Оценка сложности

- **Время**: `O(n log n)` в лучшем, среднем и худшем случаях.
  - Разделение массива даёт глубину рекурсии `log n`.
  - На каждом уровне выполняется слияние за `O(n)`.
- **Память**: `O(n)` дополнительной памяти для временных массивов.

## Как запустить
python merge_sort.py
