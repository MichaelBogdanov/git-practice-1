# Задача 03 — Переворот слов в тексте

## Участники
Борисов Арсений 3991

## Описание решения
Программа считывает текстовый файл, разбивает его на список слов, тем самым игнорируя лишние пробелы
Затем порядок элементов в списке инвертируется, и слова объединяются в строку с разделением одиночным пробелом

## Как запустить
python3 solution.py tests/input.txt
